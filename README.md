# Road Accident Analysis and Visualization

An interactive Power BI dashboard project designed to analyze road accident trends, casualty distribution, and environmental factors affecting accidents. The dashboard provides actionable insights using data visualization techniques to support road safety analysis and decision-making.

---

## 📌 Project Overview

This project focuses on analyzing road accident data to identify patterns related to:

* Accident severity
* Vehicle involvement
* Road types
* Weather conditions
* Urban vs Rural accidents
* Light conditions
* Geographic accident distribution

The dashboard enables users to explore accident statistics dynamically through filters and visual analytics.

---

## 🎯 Objectives

* Analyze yearly accident and casualty trends
* Identify high-risk road and weather conditions
* Compare casualty severity categories
* Visualize accident distribution geographically
* Generate insights for improving road safety measures

---

## 📊 Dashboard Features

### Key KPIs

* Total Casualties
* Total Accidents
* Fatal Casualties
* Serious Casualties
* Slight Casualties

### Interactive Visualizations

* Monthly casualty trends
* Casualties by vehicle type
* Urban vs Rural analysis
* Casualties by road type
* Day vs Night accident analysis
* Accident location map visualization

### Filters

* Road Surface Condition
* Weather Condition

---

## 🛠️ Tools & Technologies Used

* Power BI
* Power Query
* DAX
* Data Cleaning & Transformation
* Data Visualization

---

## 📈 Insights Generated

* Majority of casualties occurred in urban areas
* Cars contributed to the highest number of casualties
* Single carriageways recorded the maximum accidents
* Daylight conditions had higher accident counts compared to dark conditions
* Seasonal trends showed fluctuations in monthly casualty rates
